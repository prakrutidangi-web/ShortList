# SQLAlchemy 2.0 + Alembic for the data layer

**Status:** accepted

**Context:** Need migrations and first-class pgvector support.

**Decision:** SQLAlchemy 2.0 with Alembic (introduced in Phase 1).

**Alternatives:** SQLModel (less boilerplate, thinner Alembic/pgvector story).

**Consequences:** More boilerplate; widely transferable skills.
